## Estrutura do projeto

As implementações da consulta encontram-se no arquivo ```load.ipynb```, enquanto o relatório encontra-se na pasta ```docs/```.

## Executar o projeto

Crie um ambiente virtual:

```bash
python3 -m venv .venv
```

Instale as dependências do projeto:

```bash
pip install -r requirements.txt
```

Execute os exemplos no notebook.
